# 创作协作台

面向小说作者的本地 Markdown 写作 Agent。可阅读、组织和核对本地作品，也可以连接自己的模型讨论、起草和修改。稿件、人物和世界观以作品目录里的文件为准。

## Windows 上手

1. 启动开源版。可以「新建作品」「接入本地作品」，也可以点「试玩示例」生成虚构的《北岸电台》。
2. 需要 AI 时，打开「作品设置 → 模型连接」，填写服务地址和模型名。服务需要鉴权时再填 API 密钥。云端填写 OpenAI 兼容的 HTTPS 地址，本机可以填写 `http://127.0.0.1:端口/v1`。点「保存并测试连接」。
3. 在创作空间提问或引用原稿。对话框可选择已配置服务下的模型，支持模型列表的服务可拉取列表。「本次依据」记录本轮查阅的资料。
4. 在右侧「正文与草稿」打开或新建草稿。确认版本、采用 AI 建议和发布为正文由作者操作。

服务地址示例为 `https://api.deepseek.com`。模型 ID、是否支持工具和图片以及计费以服务商说明为准。OpenCode Go 仍可使用同一配置入口。兼容范围为 OpenAI Chat Completions 接口。

## 写作记忆

Windows x64 安装包内置 MemLayer 0.2.4 与独立 Python 运行时。新作品默认开启本地记忆。你可以在自己的消息下选择「存为共享记忆」，也可以核对 Agent 随回复提出的长期偏好候选。在「记忆与规则 → 共享记忆」确认后才会在后续会话生效。「本次依据 → 上轮实际」可查看实际召回和出处。支持更正及撤回。

记忆默认按作品隔离。跨作品共享须手动配置范围。本包使用本地词法检索，额外的语义模型权重和运行依赖需要独立准备。撤回会停止后续召回，原始聊天、导出和备份仍有各自的保留期限。

## 数据和网络

- 日常使用的数据位于每部作品的目录和开源版自己的应用数据目录。移机时保存整个作品目录。密钥由系统加密，绑定本机作品和服务地址。
- 使用云端模型会把本轮所需的提示、摘录和已召回记忆发送给你配置的服务。联网查询通过单独入口触发。连接测试发送虚构测试提示。
- 开源版只运行内置的稿件检查。作品目录里的外部门禁脚本可在作者自己的终端中运行。
- SenseVoice 语音识别通过用户手动配置的本地运行时提供；模型启动器可显式配置，也可直接填写已启动服务的地址。

## 开发

在 Windows x64 上安装支持 `node:sqlite` 的 Node.js。候选构建已使用 Node.js 25.2.1。

```powershell
npm ci
npm test
npm run installer
```

打包前会从 Python.org 下载嵌入运行时并比对官方 SHA-256。安装包和独立运行目录生成在 `release-public/`。快速验收和发布步骤见 [发布检查](RELEASE-CHECKLIST.md)。
