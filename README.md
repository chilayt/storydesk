# 章间

开源长篇小说创作工具。用本地 Markdown 管理稿件、人物和设定，连接自己的模型构思新书、起草和核对。章间在 GitHub 上沿用 StoryDesk 项目名称。

## 下载与上手

**[下载 Windows x64 安装包](https://github.com/chilayt/storydesk/releases/download/v2.1.0-beta.1/StoryDesk-2.1.0-beta.1-win-x64.exe)** · [发布说明和 SHA-256](https://github.com/chilayt/storydesk/releases/tag/v2.1.0-beta.1) · [首次使用说明](GETTING_STARTED.md)

当前是 Windows x64 公开测试版，安装包未签名。安装后从开始菜单打开「章间」。Python 运行时和 MemLayer 已随包提供。阅读和编辑可离线使用。

1. **接入小说**。首屏选「接入本地作品」，选择作品的总文件夹。想先空手试用，可以点「试玩示例」生成《北岸电台》。目录结构不同的作品，可在「作品设置 → 登记的资料位置」登记正文、人物和其他资料。
2. **连接模型**。左下角齿轮打开「作品设置 → 模型连接」。填服务地址、模型 ID 和按需填写的 API 密钥，勾选「启用模型连接」，点「保存并测试连接」。看到「当前测试请求成功」后返回创作空间。
3. **确认一条记忆**。在对话中写一条长期偏好，点自己消息下的「存为共享记忆」，提交候选后到「写作扩展 → 规则与作者裁定 → 共享记忆」点「确认新增」。在新对话聊相同主题，去右侧「本次依据 → 上轮实际」查看这次读到的内容和来源。

## 作品与对话

- 作品文件留在本地。接入时建立管理记录，编辑并保存会写回本地稿件。请随作品目录一起备份 `_创作管理`。
- 云端和本机共用 OpenAI 兼容的配置入口。使用云端模型时，系统会将本轮所需的提示、资料摘录与已召回记忆发送到选定服务。连接测试发送的是短样例。
- 空作品可以从一个点子开始。你可以把构思标为待探索、暂定或已确认，修改已登记的决定时查看相关人物、关系和大纲的复核项。
- 长对话分支会带上开头和近期讨论，助手可在分支内查回更早的原话。实际查阅记录在「本次依据」里可见。
- 默认沿用当前作品的叙事视角、人物声口和标点习惯。文风卡、词表和特定的标点规则可在各作品中单独配置。见[使用自己的文风与用词规则](GETTING_STARTED.md#使用自己的文风与用词规则)。

## 跨会话记忆

章间内置 MemLayer 0.3.1。比如把「术语首次出现写全称，后文用简称」确认为本作品的长期偏好，之后开启新对话，讨论相关内容时可以召回这条约定。改主意时可以对照旧约定，确认替换或加一个适用例外，也可以撤回。

完整对话保存在本地创作记录。长期记忆默认按作品隔离，作者确认后生效。使用云端模型时，本轮召回的相关记忆会随请求发送给所选服务。 [MemLayer 中文介绍](https://github.com/chilayt/memlayer/blob/main/README.zh-CN.md) · [内置版本说明](https://github.com/chilayt/memlayer/releases/tag/v0.3.1)

## 开发

在 Windows x64 上安装支持 `node:sqlite` 的 Node.js。首发构建使用 Node.js 25.2.1。

```powershell
npm ci
npm test
npm run installer
```

打包前会从 Python.org 下载嵌入运行时并校验 SHA-256。安装包生成在 `release-public/`。查看[发布验收与 Windows 签名构建](RELEASE-CHECKLIST.md)。
